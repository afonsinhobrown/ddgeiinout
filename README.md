# Gestão de Equipamentos STAE

Sistema profissional para gestão de circulação de equipamentos de TI do STAE (Central e Provincial).

## Funcionalidades
- **Fluxo de Circulação**: Controle de entradas e saídas (Interno, Provincial, Externo).
- **Interface Premium**: Design moderno com Glassmorphism.
- **Segurança**: Login com perfis diferenciados (Técnico e Proteção).
- **Automação de PDFs**: Geração automática de guias de movimentação.

## Requisitos
- Python 3.x
- Flask
- ReportLab

## Como Executar
Basta clicar no ficheiro `executar.bat` ou rodar:
```bash
pip install flask reportlab
python app.py
```
